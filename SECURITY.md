# Security & Evidence Boundary

## Principles

The MyZubster pilot-node network operates on a **zero-trust, zero-sharing** security model:

### Contributors MUST NOT share
- Private SSH keys
- Server passwords
- Database credentials
- API secrets
- Wallet seeds/private keys
- Sensitive health data

### Contributors MUST maintain
- Independent GitHub identities
- Independent repository history
- Machine-readable evidence
- Deterministic hashes
- Public, sanitized interoperability records

## Evidence Integrity

Technical `TESTED` status refers **only** to the exact interoperability checks performed. It does **not** imply:
- Laboratory verification
- Clinical validation
- Regulatory compliance
- Scientific proof
- Physical-world verification

## Contributor Node Isolation

Each contributor maintains their own:
1. GitHub identity and repository history
2. Pilot/node or verifier environment
3. Evidence bundle
4. Knowledge Card / Contributor Passport link

No cross-contributor credential sharing is required or permitted.
