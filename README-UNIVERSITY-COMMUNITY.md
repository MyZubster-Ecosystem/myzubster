# 🎓 Università · Formazione · Ricerca · GitHub

MyZubster estende la propria comunità anche a **studenti, docenti, ricercatori e tutor**, collegando formazione, ricerca open source, progetti pratici, Marketplace, Zorgax e GitHub.

L'obiettivo è permettere a una persona di trasformare un interesse accademico o formativo in un percorso pubblico e verificabile: imparare, documentare un progetto, collaborare con altri membri della community, contribuire a repository open source e costruire materiale utile per tesi, laboratori e ricerca.

| Profilo | Possibili attività in MyZubster |
|---|---|
| **🎓 Studente** | Corsi, esercitazioni, portfolio, progetti GitHub, tesi e collaborazione open source. |
| **👩‍🏫 Docente / Tutor** | Percorsi formativi, mentoring, revisione di attività e collegamento tra teoria e progetti pratici. |
| **🔬 Ricercatore** | Ricerca riproducibile, dataset autorizzati, documentazione, esperimenti e collaborazione interdisciplinare. |
| **💻 Sviluppatore** | Supporto tecnico agli studenti e ai gruppi di ricerca, repository, software, automazione e infrastruttura. |
| **🏛️ Università / Ente** | Possibili laboratori, progetti e percorsi pilota, quando esiste una reale autorizzazione dell'istituzione. |

## Come funziona

```text
STUDENTE / DOCENTE / RICERCATORE
              ↓
     PROFILO MYZUBSTER
              ↓
 CORSO / TESI / RICERCA / LABORATORIO
              ↓
          ZORGAX
              ↓
 GITHUB + COMMUNITY + MARKETPLACE
              ↓
 DOCUMENTAZIONE / CODICE / EVIDENZE
              ↓
       REVISIONE UMANA
```

La Community contiene l'area **Università · Formazione · Ricerca · GitHub**. I profili accademici possono indicare ruolo, università o ente, area di studio e profilo GitHub pubblico. Il Marketplace include percorsi dimostrativi per **corsi e formazione, tesi, ricerca, tirocini e laboratori**.

Zorgax dispone di un percorso dedicato **Università e ricerca**: può aiutare a definire un obiettivo, organizzare un progetto, individuare documentazione o repository pertinenti e guidare la persona verso le aree della Community. Zorgax è uno strumento di assistenza: non sostituisce docenti, tutor, revisori scientifici o istituzioni.

## GitHub come laboratorio aperto

GitHub permette di rendere il lavoro tecnico e documentale versionato e verificabile. Uno studente può partire da una issue, creare un branch, sviluppare o documentare una soluzione, eseguire test e proporre una pull request. Ricercatori e docenti possono usare lo stesso modello per materiali, software e metodologie quando la pubblicazione è autorizzata.

```text
IDEA / DOMANDA DI RICERCA
          ↓
       ISSUE
          ↓
   BRANCH / PROGETTO
          ↓
 CODICE / DATI / DOCUMENTAZIONE
          ↓
       TEST
          ↓
   PULL REQUEST
          ↓
 REVISIONE / FEEDBACK
          ↓
 RISULTATO VERSIONATO
```

Questo rende possibile anche la collaborazione con le altre aree MyZubster: sviluppatori possono aiutare ricercatori e studenti con strumenti digitali; agricoltori e comunità locali possono proporre problemi reali da studiare quando autorizzati; artisti e sound system possono contribuire a ricerche culturali e creative; i percorsi LIFE-oriented possono diventare casi di studio o candidati pilota senza essere automaticamente riconosciuti come progetti istituzionali.

## Confini e riconoscimento accademico

Una issue, una pull request, un corso, una demo o un'attività svolta su MyZubster **non attribuisce automaticamente crediti universitari, certificazioni, borse di studio, tirocini riconosciuti o titoli accademici**. Qualsiasi riconoscimento formale deve essere approvato dal docente, dall'università o dall'ente competente.

Dati, fotografie, ricerche e materiali devono avere provenienza e autorizzazioni adeguate. Informazioni personali, dati di ricerca riservati e materiale appartenente a partner o istituzioni non devono essere pubblicati senza autorizzazione.
