# MyZubster Android TV / Google TV app

This directory contains a minimal native Android TV launcher app for MyZubster.

## Current architecture

- Native `LEANBACK_LAUNCHER` entry point.
- Landscape fullscreen activity.
- Standard Android `WebView` loads `https://myzubster.com/tv.html` over HTTPS.
- Remote/D-pad input is handled by the TV web surface; Android Back navigates WebView history before exiting.
- No tokens, cookies, camera, microphone, storage or location permissions are requested by the app.

## Build

Open `android-tv/` in Android Studio with JDK 17 and build the `app` module, or use a Gradle wrapper once generated by Android Studio/CI.

Expected package: `org.myzubster.tv`

## Verification boundary

This commit provides a buildable project scaffold but does **not** claim a successfully built APK, Play Store acceptance, or verified behavior on a physical Google TV device. Those require Android build/CI plus a real-device QA pass.

The hosted TV page must also be deployed at `https://myzubster.com/tv.html` before the wrapper is useful in production.
