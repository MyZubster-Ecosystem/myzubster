🌐 MyZubster Metaverse Interoperability

Le osservazioni MyZubster possono essere trasformate in entità 3D con provenance attraverso vertical slice sperimentali e riproducibili. Il lavoro corrente copre Vircadia World e Decentraland SDK7: è interoperabilità open-source in sviluppo, non una partnership o endorsement delle piattaforme.

Vircadia WorldBabylon.jsDecentraland SDK7ECSProvenance
🪐
Vircadia World
3 marker MyZubster persistiti nel runtime Vircadia e renderizzati nel client Babylon.js con prova CI.
🏙️
Decentraland Gateway
Scena SDK7 con marker interattivi e MyZubster Gateway per navigare tra place, plant ed environment.

Interoperability Track
Track tecnico evidence-first per portare dati pubblici/sanificati MyZubster in mondi immersivi.

🌍 Public Community Activity

MyZubster pubblica una vista evidence-first delle interazioni verificabili della community. Contributi, PR, review, segnalazioni e test indipendenti possono diventare evidenza pubblica; le semplici visite restano anonime e non vengono usate per identificare le persone.
