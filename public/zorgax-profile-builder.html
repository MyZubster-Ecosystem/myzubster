🔎 Esplora i repository pubblici e scegli contributi documentati

Questa ricerca usa soltanto l’API pubblica di GitHub. Seleziona un repository Monero, Tari o MyZubster, oppure inseriscine un altro. Solo una PR o un commit specifico che scegli e confermi può diventare una fonte della Knowledge Card. Un fork non dimostra di per sé la creazione del codice originale.

Repository principale
La ricerca è in sola lettura: nessuna fonte sarà collegata automaticamente.

Se il fork o una PR non è accessibile senza autenticazione, Zorgax non può usarla come fonte pubblica. Verifica che il link si apra in una finestra anonima; in alternativa scegli commit o PR realmente pubblici di altri repository. Non riproporre una PR con errore 404: potrebbe essere limitata da GitHub.
