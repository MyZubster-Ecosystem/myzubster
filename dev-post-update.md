# MyZubster AI Automation: Documentazione e Guida dell'Orto Intelligente

## 🎉 Novità

Il progetto MyZubster ha compiuto un grande passo avanti con l'integrazione di un sistema di automazione AI e la pubblicazione di una guida completa per l'orto intelligente.

## 🌱 Nuova Documentazione

Sono stati aggiunti **5 documenti bilingue (IT+EN)** alla documentazione ufficiale:

| Documento | Contenuto |
|-----------|-----------|
| **Guida orto intelligente** | Guida pratica per agricoltori e hobbisti |
| **Piano didattico scuole** | Programma educativo per scuole (11-18 anni) |
| **Protocollo validazione** | Validazione scientifica dei sensori |
| **Template orto comunitario** | Setup e gestione orti comunitari |
| **Progetto orti scolastici** | Kit ecologico per scuole |

## 🤖 Sistema AI Automation

Il sistema ora include:

### 1. Bot Telegram (@myzubster_bot)
- 📱 Notifiche in tempo reale
- 🔍 Analisi AI delle issue
- 💰 Gestione bounty
- 📊 Stato del sistema

### 2. GitHub Monitor
- 🐙 Monitoraggio automatico issue e PR
- 🔔 Notifiche su Telegram
- 🏷️ Gestione label automatica

### 3. AI Orchestrator
- 🧠 Analisi con Gemma, Llama, DeepSeek
- 🔄 Fallback automatico tra modelli
- 📝 Generazione automatica bounty

### 4. Webhook Integration
- 🔗 Ricezione eventi da GitHub
- ⚡ Risposta in tempo reale
