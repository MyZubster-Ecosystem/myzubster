## 📌 What is MyZubster?

MyZubster is a **decentralized ecosystem** for registering and verifying **animals and plants** on the **Monero (XMR) blockchain**. Every registration becomes a permanent, verifiable record — accessible to anyone, anywhere.

### Core Services

| Service | Description |
|---------|-------------|
| 🐾 **Animal Registry** | Register pets, livestock, wildlife, and more |
| 🌍 **Plant Map** | Register trees, plants, and forests |
| 🗺️ **Animal Map** | Interactive map for animal registry |
| 🔗 **Gateway** | Backend API for Monero payments |

## 🚀 How to Register

### Register an Animal

1. **Identify** – Take photos, note species and GPS
2. **Submit** – Use the [animal-registration template](https://github.com/DanielIoni-creator/myzubster-animal-registry/issues/new/choose)
3. **Verify** – Get verified by other users
4. **Earn** – Receive 0.001 XMR for registration + 0.002 XMR for verification

### Register a Plant

1. **Identify** – Take photos, note species and GPS
2. **Submit** – Use the [plant-registration template](https://github.com/DanielIoni-creator/-MyZubster---Global-Plant-Map-powered-by-Monero-blockchain/issues/new/choose)
3. **Verify** – Get verified by other users
4. **Earn** – Receive 0.001 XMR for registration + 0.002 XMR for verification
