# 🚗 Urban Lab Auto – L'auto elettrica open source

Benvenuto nel repository dell'**Urban Lab Auto**, l'auto elettrica open source che guadagna MYZ per ogni chilometro percorso.

## 📦 Specifiche

| Componente | Dettaglio |
|------------|-----------|
| **Motore** | Elettrico 48V 5kW |
| **Batteria** | LiFePO4 72V 100Ah |
| **Autonomia** | 150-200 km |
| **Velocità max** | 80 km/h |
| **Peso** | 350 kg (a vuoto) |
| **Posti** | 2 (configurabile) |
| **Sensori** | GPS, lidar, telecamere |
| **Software** | Open source (ESP32/Raspberry Pi) |

## 💰 Pagamenti e ricompense

- **Noleggio**: pagamento in XMR con escrow multisig
- **Ricompense**: 0.5 MYZ per ogni km percorso
- **Bonus**: 50 MYZ ogni 500 km

## 📂 Contenuto

- `cad/` – File CAD (STEP, STL, F3D)
- `electronics/` – Schemi elettrici e PCB
- `firmware/` – Firmware per ESP32/Raspberry Pi
- `bom/` – Bill of Materials
- `assembly/` – Guide di assemblaggio
- `docs/` – Documentazione tecnica
- `licenses/` – Licenza CERN OHL
