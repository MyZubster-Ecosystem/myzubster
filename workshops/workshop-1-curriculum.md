# Workshop 1: Smart Gardening 101

## Detailed Curriculum

**Duration:** 60 minutes  
**Level:** Beginner  
**Prerequisites:** None

---

## 📚 Learning Objectives

By the end of this workshop, participants will be able to:
1. Explain what smart gardening is
2. Identify common garden sensors
3. Set up basic data collection
4. Use data to improve plant care decisions

---

## 📝 Workshop Agenda

### 0:00 - 0:15 | Introduction

**Slides: What is Smart Gardening?**

- Definition and benefits
- Real-world examples
- MyZubster overview

**Discussion Questions:**
- What challenges do you face in your garden?
- How could technology help?

---

### 0:15 - 0:35 | Sensors Deep Dive

**Types of Sensors**

| Sensor | What it Measures | Why it Matters |
|--------|------------------|----------------|
| Soil Moisture | Water level in soil | Prevent over/under watering |
| Temperature | Air/soil temperature | Protect from frost/heat |
| Humidity | Air moisture | Prevent fungal diseases |
| Light | Sunlight hours | Optimize plant placement |
| pH | Soil acidity | Ensure nutrient availability |

**Demo:** Live sensor readings

---

### 0:35 - 0:50 | Data Collection

**Setting Up Monitoring**

1. Connect sensors to gateway
2. Configure data intervals
3. Set up alerts

**Understanding Your Data**

- Daily/weekly trends
- Seasonal patterns
- Correlation analysis

**Hands-On Exercise:**
- View sample dashboard
- Identify patterns in data

---

### 0:50 - 1:00 | Wrap-Up & Q&A

**Key Takeaways**
- Smart gardening = data-driven gardening
- Start small, scale gradually
- MyZubster helps you get started

**Next Steps**
- Sign up for MyZubster
- Join Discord community
- Try Workshop 2: AI for Plant Care

## 🎯 Exercises

### Exercise 1: Sensor Identification (5 min)
Identify which sensors would help with:
- Tomato plants
- Succulents
- Herb garden

### Exercise 2: Data Interpretation (10 min)
Given sample data, answer:
1. When did the plant need water?
2. What was the optimal temperature range?
3. Were there any unusual readings?

### Exercise 3: Action Planning (5 min)
Create a monitoring plan for your garden:
- Which sensors to use
- Data collection frequency
- Alert thresholds
