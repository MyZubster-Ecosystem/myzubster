# 🎓 MyZubster Educational Workshop Series

## Overview

A series of educational workshops combining gardening knowledge with modern technology.

**Format:** Monthly workshops (virtual or in-person)  
**Duration:** 60-90 minutes per session  
**Audience:** Gardeners, developers, tech enthusiasts

---

## 📅 Workshop Schedule

| # | Title | Duration | Level |
|---|-------|----------|-------|
| 1 | Smart Gardening 101 | 60 min | Beginner |
| 2 | AI for Plant Care | 75 min | Intermediate |
| 3 | Blockchain for Permaculture | 75 min | Intermediate |
| 4 | Building with MyZubster | 90 min | Advanced |

## 🌱 Workshop 1: Smart Gardening 101

### Learning Objectives
- Understand IoT sensors for gardens
- Set up basic monitoring systems
- Use data to improve plant care

### Curriculum

**Part 1: Introduction (15 min)**
- What is smart gardening?
- Benefits of technology in gardening
- Overview of sensors and devices

**Part 2: Sensors (20 min)**
- Soil moisture sensors
- Temperature and humidity
- Light meters
- pH sensors

**Part 3: Data Collection (15 min)**
- Setting up data logging
- Understanding readings
- Setting thresholds

**Part 4: Hands-On (10 min)**
- Demo: Setting up a basic sensor
- Reading data with MyZubster

### Materials Needed
- Slide deck
- Sensor kit (optional)
- MyZubster account

### Resources
- [Sensor Guide](../docs/sensors.md)
- [Data Logging Tutorial](../docs/data-logging.md)
