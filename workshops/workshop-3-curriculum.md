# Workshop 3: Blockchain for Permaculture

## Detailed Curriculum

**Duration:** 75 minutes  
**Level:** Intermediate  
**Prerequisites:** Basic understanding of gardening

---

## 📚 Learning Objectives

By the end of this workshop, participants will be able to:
1. Explain blockchain fundamentals
2. Understand crypto rewards in gardening
3. Set up and use a crypto wallet
4. Participate in the MyZubster bounty system

---

## 📝 Workshop Agenda

### 0:00 - 0:20 | Blockchain Basics

**What is Blockchain?**
- Distributed ledger technology
- Immutability and transparency
- Decentralization benefits

**Cryptocurrency Overview**
- Bitcoin, Ethereum, Monero
- How transactions work
- Wallets and keys

---

### 0:20 - 0:40 | Permaculture & Crypto

**Tokenizing Sustainable Practices**
- Rewarding eco-friendly actions
- Community governance
- Transparent impact tracking

**MyZubster Token System**
- How rewards work
- Earning opportunities
- Using tokens in ecosystem

**Demo:** Live token earning demonstration

---

### 0:40 - 0:55 | Hands-On Wallet Setup

**Setting Up Your Wallet**
1. Choose a wallet type
2. Create new wallet
3. Secure your keys
4. Receive your first tokens

**Exercise:** Create wallet and receive test tokens

---

### 0:55 - 1:15 | Bounty System & Q&A

**Participating in Bounties**
- Finding available bounties
- Claiming and completing
- Submitting work
- Receiving rewards

**Demo:** Complete a sample bounty

**Q&A Session**

---

## 🎯 Exercises

### Exercise 1: Wallet Setup (15 min)
1. Create a new wallet
2. Secure backup phrase
3. Receive test tokens

### Exercise 2: Bounty Hunt (15 min)
1. Find 3 open bounties
2. Evaluate difficulty
3. Choose one to claim

### Exercise 3: Token Economics (10 min)
1. Calculate potential earnings
2. Plan bounty strategy
3. Set goals
