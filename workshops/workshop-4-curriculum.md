# Workshop 4: Building with MyZubster

## Detailed Curriculum

**Duration:** 90 minutes  
**Level:** Advanced  
**Prerequisites:** Workshops 1-3, basic coding knowledge

---

## 📚 Learning Objectives

By the end of this workshop, participants will be able to:
1. Understand MyZubster architecture
2. Contribute to the codebase
3. Build custom integrations
4. Deploy their own instance

---

## 📝 Workshop Agenda

### 0:00 - 0:15 | Architecture Overview

**System Components**
- Backend API (Node.js/Express)
- Database (SQLite)
- Frontend (React)
- Mobile App (Kotlin)

**Data Flow**
- User interactions
- API calls
- Database operations
- Real-time updates

---

### 0:15 - 0:40 | API Deep Dive

**REST API Endpoints**
- Plants, Animals, Bounties
- Authentication
- Geolocation

**Authentication System**
- JWT tokens
- User roles
- Protected routes

**Demo:** API exploration with Postman

---

### 0:40 - 1:10 | Building Features

**Creating New Routes**
1. Define endpoint
2. Add controller logic
3. Update database model
4. Test implementation

**Hands-On:** Build a simple API endpoint

**Frontend Integration**
- React components
- API client
- State management

---

### 1:10 - 1:30 | Deployment & Q&A

**Docker Setup**
- Containerization
- Environment variables
- Production deployment

**Going Live**
- Domain setup
- SSL certificates
- Monitoring

**Q&A Session**

---

## 🎯 Exercises

### Exercise 1: Code Exploration (15 min)
1. Navigate codebase
2. Identify key files
3. Understand data flow

### Exercise 2: API Development (20 min)
1. Create new endpoint
2. Add database table
3. Test with curl/Postman

### Exercise 3: Deployment (15 min)
1. Set up Docker
2. Configure environment
3. Launch local instance
