# MyZubster Forkable Project Templates

Questa directory raccoglie starter riutilizzabili per trasformare le categorie della community in progetti GitHub documentati, forkabili e migliorabili tramite pull request.

## Starter disponibili
- `fork-starter/` base comune: PROFILE, PILOT, SERVICES
- `university-research/` studenti, universita, ricerca e formazione
- `developer/` sviluppo e supporto tecnico trasversale
- `life-pilot/` progetti e casi pilota LIFE
- `soundsystem-events/` sound system, DJ, eventi e culture underground
- `agriculture-circular/` agricoltura, acqua, canapa, kefir ed economia circolare
- `services-trades/` artigiani e servizi professionali
- `animals/` dogsitter, animali smarriti e supporto community

## Workflow
Fork -> scegli starter -> compila profilo -> definisci pilot/servizi -> aggiungi evidenze -> apri issue -> sviluppa -> proponi miglioramenti upstream con pull request.

Gli starter sono intenzionalmente semplici: ogni progetto puo estenderli mantenendo compatibilita con la struttura comune MyZubster.
