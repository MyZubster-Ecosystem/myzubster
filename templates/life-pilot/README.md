# MyZubster LIFE Pilot Starter

Template per trasformare una persona, organizzazione o filiera in un caso pilota documentato.

## Scheda minima
1. Problema ambientale/sociale affrontato.
2. Territorio e soggetti coinvolti.
3. Soluzione proposta.
4. Ruolo di MyZubster e Zorgax.
5. Attivita e milestone.
6. Indicatori misurabili.
7. Evidenze e documenti.
8. Possibilita di replicazione/fork.

## Aree esempio
Circular Care, acqua, agricoltura, canapa, eventi/community, marketplace, metaverso e altri pilot compatibili.
