# MyZubster Developer Starter

Template forkabile per sviluppatori che vogliono aiutare le diverse categorie della community.

## Attivita
- sviluppo web e mobile;
- integrazioni API e automazioni;
- AI/Zorgax e strumenti locali;
- Marketplace e profili;
- deployment, test e documentazione;
- supporto tecnico ai pilot.

## Struttura
- `src/` codice del progetto
- `docs/` documentazione tecnica
- `examples/` demo riproducibili
- `tests/` test
- `integrations/` integrazioni

Documenta sempre installazione, dipendenze, configurazione senza segreti e procedura per riprodurre il lavoro.
