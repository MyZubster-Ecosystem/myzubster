# Fork Readiness Checklist

Usa questa checklist prima di pubblicare un pilot o chiedere contributi.

## Identita
- [ ] PROFILE.md compilato
- [ ] competenze e ruolo descritti
- [ ] contatti pubblici solo se si desidera condividerli

## Pilot
- [ ] problema reale descritto
- [ ] obiettivo verificabile
- [ ] attivita e responsabili definiti
- [ ] KPI definiti
- [ ] evidenze salvate in docs/assets/results

## Servizi
- [ ] offerte e richieste descritte
- [ ] area geografica o modalita remota indicata quando utile
- [ ] condizioni e limiti chiari

## Open source
- [ ] nessun segreto, token o dato personale nel repository
- [ ] licenze delle risorse verificate
- [ ] issue piccole e comprensibili
- [ ] README spiega come contribuire
- [ ] modifiche riutilizzabili proposte upstream tramite pull request

## Definition of Done
Il fork e pronto quando una persona esterna puo capire in pochi minuti chi partecipa, quale problema viene affrontato, come contribuire e come verificare i risultati.
