# MyZubster Animals Starter

Template per servizi e iniziative legate agli animali: dogsitter, supporto per animali smarriti, associazioni e servizi della community.

## Casi demo
- ricerca di un dogsitter;
- segnalazione di animale smarrito;
- richiesta/offerta di supporto locale.

## Cartelle
- `services/`
- `lost-found/`
- `community/`
- `media/`

Per segnalazioni pubbliche evita di inserire indirizzi privati o altri dati personali non necessari.
