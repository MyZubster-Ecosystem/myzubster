# MyZubster Globalization Roadmap 2026–2028

_Status: working roadmap · Updated 2026-08-25_

## North Star

Move MyZubster from an open-source ecosystem with an Italian reference base to an independently reproducible international network built on verifiable evidence.

```text
OPEN SOURCE → OPEN COMMUNITY → VERIFIED PILOT → REPLICATION KIT → INTERNATIONAL NODE → GLOBAL NETWORK
```

This roadmap distinguishes implemented capabilities, experiments, discussions and future targets. A discussion is not a partnership; a deployment is not adoption; a LIFE planning track is not an approved or funded LIFE project.

## Phase 1 — Consolidation · Aug–Oct 2026

Goal: make MyZubster understandable, testable and measurable without direct assistance from the core team.

- consolidate myzubster.com;
- surface Join, Community Activity, Zorgax and DAO clearly;
- operate privacy-respecting web analytics;
- provide an international quickstart/onboarding path;
- collect at least 10 independent first-time validations;
- fix onboarding failures found by external testers;
- keep `implemented / experimental / proposed` states explicit;
- use Zorgax to help route and classify evidence without replacing human review.

**Exit KPI:** at least 10 independent people can execute a documented MyZubster workflow and provide reproducible evidence.

## Phase 2 — Italian Reference Pilot · Sep–Dec 2026

Goal: produce one small, authorized and independently reviewable end-to-end territorial/environmental vertical slice.

```text
AUTHORIZED DATA
      ↓
   MyZubster
      ↓
    Zorgax
      ↓
PROVENANCE + VALIDATION
      ↓
      KPI
      ↓
HUMAN TECHNICAL / SCIENTIFIC REVIEW
      ↓
DASHBOARD / EVIDENCE
```

Working objectives:

- define scientific methodology and KPI with an appropriate scientific counterpart;
- formalize exactly which partner datasets can be used, under which rights and governance;
- select one manageable territorial use case;
- ingest a controlled sample dataset;
- produce at least one validated KPI/evidence record;
- publish only sanitized material for which publication is authorized.

Current discussions with UNIBO, Agrosistemi, Urban Lab and other actors must remain described according to their actual documented status until roles are formally agreed.

**Exit KPI:** one real end-to-end vertical slice with external reviewable evidence.

## Phase 3 — Replication Kit · Nov 2026–Feb 2027

Goal: turn the Italian reference implementation into a reusable protocol.

```text
MyZubster Global Pilot Kit
├── Quickstart
├── Data schemas
├── API specification
├── Zorgax workflow
├── Provenance rules
├── KPI templates
├── Validation protocol
├── Privacy/data-governance checklist
├── Dashboard template
├── Governance boundaries
└── Replication guide
```

The critical test is whether another territory can replace the reference dataset with an authorized local dataset without rewriting the core architecture.

**Exit KPI:** an external developer/operator can reproduce the reference workflow using public documentation.

## Phase 4 — LIFE 2027 Preparation · Jan–Spring 2027

Goal: prepare a defensible proposal architecture if/when an appropriate official LIFE 2027 call/topic is confirmed.

The proposal logic should be:

```text
PROBLEM → METHODOLOGY → TECHNOLOGY → PARTNERS → PILOT → KPI → EVIDENCE → REPLICATION → IMPACT
```

The reference pilot should provide technical evidence. Zorgax should provide bounded evidence automation. Scientific and consortium roles must only be described as confirmed when formally documented.

**Important:** LIFE 2027 is a planning direction. No wording in this repository should imply EU approval, funding or endorsement before it exists.

## Phase 5 — First International Node · Q1–Q2 2027

Goal: obtain the first independently evidenced replication outside Italy.

Rather than opening many countries at once, select one suitable external territory/community/organization with accessible data and a realistic operator.

```text
ITALY REFERENCE PILOT
        ↓
REPLICATION PACKAGE
        ↓
FIRST INTERNATIONAL NODE
        ↓
LOCAL AUTHORIZED DATA
        ↓
INDEPENDENT REPRODUCTION
```

Possible geographies must be selected based on evidence and readiness, not promotional value. Singapore or another territory may be evaluated; no location is considered a confirmed node until an independent activity actually occurs.

**Exit KPI:** one externally operated deployment/test/pilot outside Italy with reproducible evidence.

## Phase 6 — Multi-region Replication · Q2–Q4 2027

Goal: expand only after the first international replication works.

Target architecture:

```text
                 MyZubster
                     │
              Global Protocol
          ┌──────────┼──────────┐
          ↓          ↓          ↓
       Italy       Node #2    Node #3
          │          │          │
          └────── Zorgax ───────┘
                     │
               Evidence Layer
```

Expansion to jurisdictions with materially different hosting, data-governance or infrastructure constraints — including China — requires a dedicated compatibility and compliance track rather than assuming the European deployment model can simply be copied.

**Exit KPI:** activity verified in at least 3 territories with comparable evidence structures.

## Phase 7 — International Governance · 2027–2028

Goal: progressively move community coordination from a core-team model toward transparent multi-stakeholder participation where appropriate.

Potential participant classes:

- developers;
- researchers;
- pilot operators;
- local communities;
- data contributors;
- reviewers.

Zorgax may prepare evidence, summaries and proposals. It must not autonomously approve scientific claims, partnerships, treasury movements or other consequential governance actions.

**Exit KPI:** repeatable public governance processes with participation beyond the founding/core group.

## Phase 8 — MyZubster Global Network · 2028

Goal: establish a network where the same evidence/provenance protocol is independently reusable across multiple territories.

```text
                 MYZUBSTER
                     │
              GLOBAL PROTOCOL
                     │
                  ZORGAX
                     │
             EVIDENCE NETWORK
                     │
        ┌────────────┼────────────┐
        ↓            ↓            ↓
      EUROPE        ASIA       OTHER REGIONS
        │            │            │
      PILOTS       PILOTS        PILOTS
        └────────────┼────────────┘
                     ↓
              OPEN COMMUNITY
                     ↓
             GOVERNANCE LAYER
```

Globalization is reached through independent replication, not translation alone.

## March 2027 milestone

By March 2027, the target is to have:

1. one verifiable Italian vertical slice;
2. a public Replication Kit;
3. at least one external actor beginning an independent international reproduction.

This is a target, not a claim of completion.

## Evidence rules

Every globalization claim should answer:

- **Who** independently performed the activity?
- **What** exactly was run, tested or deployed?
- **Where** is the public/sanitized evidence?
- **Which commit/version** was used?
- **Can another party reproduce it?**

Passive traffic is interest. Public contribution is participation. Independent reproduction is adoption evidence. Authorized real-world pilots are operational evidence.
