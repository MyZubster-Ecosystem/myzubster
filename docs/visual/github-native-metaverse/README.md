# Zorgax Visual #003 — GitHub-Native Metaverse

**Category:** Architecture / How it works  
**Status:** Draft visual package  
**Date:** 2026-08-22

This package explains the MyZubster concept as a GitHub-native, evidence-first digital/physical ecosystem.

## Core flow

```text
Repository
   ↓
Issue / Mission
   ↓
Contributor
   ↓
Work + Evidence
   ↓
Pull Request / Submission
   ↓
Review + Verification
   ↓
Verified ecosystem change
   ↓
MyZubster World state
```

The visual is intentionally careful about evidence boundaries:

- an issue is not a completed mission;
- a pull request is not an accepted contribution;
- a merge is not proof of external payment;
- an AI/Canva illustration is narrative, not evidence;
- verified public records and canonical repository state remain authoritative.
