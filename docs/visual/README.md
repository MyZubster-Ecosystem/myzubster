# MyZubster Visual Architecture

This directory contains evidence-aware visual documentation produced for the MyZubster ecosystem.

## Visual #001 — Zorgax Ecosystem Architecture Map

![Zorgax architecture map](./myzubster-ecosystem-architecture-zorgax-001.svg)

Purpose: translate the canonical architecture in [`../ECOSYSTEM.md`](../ECOSYSTEM.md) into a cyberpunk visual that improves onboarding without changing technical claims.

Key boundaries preserved in the visual:

- App/Web feed the core/platform layer.
- Public snapshots are sanitized and content-addressed through IPFS/IPNS.
- External settlement remains behind the Gateway/integration boundary and requires independent verification.
- AI automation, robotics and IoT are shown as experimental/prototype tracks rather than production claims.
- Repository names describe responsibility boundaries; they do not prove production readiness.
