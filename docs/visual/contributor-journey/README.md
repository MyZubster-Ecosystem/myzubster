# Visual #006 — Contributor Journey

Interactive, evidence-first contributor journey for MyZubster.

## Flow

```text
DISCOVER
  → ENTER GITHUB
  → FIND ISSUE / MISSION
  → DO AUTHORIZED WORK
  → SUBMIT PR / EVIDENCE
  → REVIEW + VERIFICATION
  → VERIFIED CONTRIBUTION
  → WORLD STATE
```

## Guardrails

- discovering MyZubster is not adoption;
- opening a PR is not acceptance;
- merge is not proof of external payment;
- AI-generated visuals are illustrative, not evidence;
- only reviewed and appropriately verified work should be represented as a verified ecosystem change.
