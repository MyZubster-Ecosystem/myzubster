ZORGAX VISUAL #006

Contributor Journey

From discovery to a verified ecosystem change. The journey is intentionally evidence-first: participation is visible, but status only advances when the required review or verification exists.

01

Discover

Find MyZubster through GitHub, docs, a Chronicle or an external source.

02

Enter GitHub

Read repository context, contribution rules and public project status.

03

Mission / Issue

Select an issue, mission or scoped objective with acceptance criteria.

04

Do the Work

Code, documentation, tests, data, design or authorized real-world evidence.

05

Submit Evidence

Open a PR or submission and link the relevant issue, changes and proof.

06

Review + Verify

Maintainers/community review code, tests, evidence and mission criteria.

07

World State

If accepted, the verified change becomes part of the public ecosystem history.

What can count as evidence?

Pull requests, commits, code changes, tests, documentation, linked issues, public logs/screenshots and other appropriate verifiable artifacts.

What does not automatically count?

Roadmaps, ideas, private work, unpublished forks, unsupported claims, a PR without review, or an AI-generated illustration.

Guardrails: PR opened ≠ accepted contribution · PR merged ≠ external payment · AI visual ≠ evidence · roadmap ≠ released feature.
