## Rule

Every item in this catalog is **AI-generated / illustrative / NOT EVIDENCE** unless a separate repository-native asset explicitly says otherwise.

Publishing an image in `MyZubster-Visual` makes it publicly versioned and inspectable; it does **not** upgrade its evidentiary status.

The PNGs may be useful for storytelling, README decoration, Chronicle covers and presentation material, but they must not be used to prove:

- implementation or deployment state;
- metrics, users, contributors or geography;
- external integrations or partnerships;
- bounty completion, reward payment or settlement;
- identity/KYC, employment or affiliation;
- system health, adoption or production readiness.

Canonical claims remain grounded in GitHub repository state, public issues/PRs, canonical docs, runtime evidence and independently verifiable records.
