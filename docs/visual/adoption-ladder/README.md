# Visual #009 — Adoption Ladder

Evidence-first vocabulary for describing external reach without turning discovery into adoption.

```text
DISCOVERY → INTEREST → FORK/CLONE → CONTRIBUTION → INTEGRATION → DEPLOYMENT → VERIFIED ADOPTION
```

## Why this exists

MyZubster appears in public repositories, project-authored publications and third-party indexes/aggregators. These signals have different evidentiary strength. A search result, mirror, index entry or article is not proof that an external organization actively uses MyZubster.

## Ladder

| Level | Meaning | Minimum evidence |
|---|---|---|
| DISCOVERY | MyZubster is publicly discoverable outside its canonical repository/site. | Independent indexed page, directory, mirror or third-party mention. |
| INTEREST | A third party explicitly expresses interest or engages with the project. | Public comment, issue, discussion or attributable communication safe to publish. |
| FORK / CLONE | Repository activity shows a copy/fork/clone-like public development path. | Public GitHub fork or repository with traceable ancestry. |
| CONTRIBUTION | External contributor submits reviewable work. | Issue/PR/commit with attributable public evidence. |
| INTEGRATION | Another project demonstrably integrates a MyZubster component/interface. | Public code/config/docs plus reproducible integration evidence. |
| DEPLOYMENT | The integration is running in a real environment. | Runtime/deployment evidence appropriate to the claim. |
| VERIFIED ADOPTION | An external party demonstrably uses the system and the adoption claim has been independently checked. | Named external evidence, reproducible deployment/use evidence, and review. |

## Current evidence boundary

As of 2026-08-22, public web checks support **DISCOVERY** signals, including third-party indexing/republication of MyZubster-related material. They do not by themselves establish external deployment, partnership, endorsement or verified adoption.

Project-authored DEV posts and MyZubster's own website are useful chronology/context, but are not independent adoption evidence.

## Guardrails

- indexing ≠ endorsement;
- article republication ≠ integration;
- GitHub fork ≠ deployment;
- contributor activity ≠ institutional adoption;
- roadmap ≠ released capability;
- AI-generated visual ≠ evidence;
- adoption status must never be stronger than its linked evidence.
