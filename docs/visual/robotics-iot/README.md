## Shared model

`Mission → Robot/simulator → Telemetry → Persistence/Audit → API/Dashboard → Gateway boundary`

## Evidence boundaries

- repository/source existence does not prove physical deployment;
- simulation evidence does not prove hardware validation;
- hardware validation requires actual device/safety evidence;
- autonomous purchasing, self-replication and external settlement remain research/prototype claims unless separately demonstrated;
- internal MYZ accounting is not external payment evidence;
- the Space Station repository is a software vertical slice and does not imply a physical or orbital facility.

Human review is required before promoting any component to a stronger maturity or runtime state.
