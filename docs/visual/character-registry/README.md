# Visual #010 — Character Registry

The Character Registry is an evidence-first view for Git-linked MyZubster characters and contributor/component roles.

## Canonical source

The view reads:

`docs/visual/data/evidence.json`

This is the same dataset used by World State, Adoption Ladder and Chronicle.

## Character states

`PROPOSED → REVIEWED → VERIFIED_CONTRIBUTOR → ACTIVE`

These states describe the registry/visual workflow only. `VERIFIED_CONTRIBUTOR` means a public contribution can be linked to suitable repository evidence. It does not mean legal identity verification, KYC, employment, partnership, payment, endorsement or ownership.

## Evidence rules

- character art is not contribution evidence;
- AI-generated character art must remain labelled as AI-generated;
- Issue #617 is currently a public invitation, not proof that a character has been submitted;
- repository, issue, PR and commit links form the evidence layer;
- external projects/tools must be marked `external integration / no affiliation` unless a relationship is independently verifiable.

## Entry point

Public invitation: `https://github.com/MyZubster-Ecosystem/myzubster/issues/617`
