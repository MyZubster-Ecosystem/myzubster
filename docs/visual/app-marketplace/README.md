## Verified repository status

Both public READMEs describe their repositories as **Development / active validation**.

### App

The App README documents a React Native / Expo client with authentication, orders, wallet/payment-facing UI contracts and privacy/Orbot experiments. It explicitly warns that a client screen/API request does not prove a payment rail is available or externally settled, and that Tor routing requires independent verification.

### Marketplace

The Marketplace README documents garden and sensor API areas and historical bounty-linked development. It explicitly warns that endpoint lists must be verified against the current implementation and tests, and that bounty labels/amounts are not evidence of external settlement.

## Evidence role

This package is a repository architecture/status reference. It is not evidence of production deployment, external settlement, commercial adoption, or Tor routing.
