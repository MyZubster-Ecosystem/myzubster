# Darkode Historical Evidence Archive

This directory contains a public-safe archive of historical material reviewed on 2026-08-20.

Purpose: preserve technical provenance relevant to the MyZubster digital-identity work while keeping personal and financial data private.

## Files

- `dossier-storico-darkode-transazioni.md` — source dossier imported from Drive.
- `verification-addendum.md` — verification notes, evidence boundaries and cryptographic commitments.
- `darkode-2015-membership-evidence-public.svg` — public SVG container embedding an optimized derivative of the historical attachment.

## Evidence policy

This archive must not be interpreted as proof of unlawful activity or as a complete legal identity verification.

Historical emails and wallet-related material are treated as provenance evidence. Sensitive values such as personal email addresses, Bitcoin addresses, wallet identifiers, unsubscribe tokens, credentials, keys and recovery material are not published here.

The original private evidence should be retained separately so the public SHA-256 commitments can be checked later when appropriate.
