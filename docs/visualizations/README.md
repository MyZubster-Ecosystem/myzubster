## Visual standard

Use the approved dark/neon MyZubster system consistently across repository assets:

- repository role and scope
- architecture / dependency flow
- technology stack
- CI/CD health
- deploy / uptime status
- recent activity and contributors
- video / animation storyboard or thumbnail

## Animation workstream

For each repository, produce:

1. 16:9 hero visualization.
2. Architecture/dependency frame.
3. CI/deploy/status frame.
4. 30–45 second animation storyboard.
5. Final video export when the video-generation pipeline is available.

## Storage model

- GitHub: reviewable index, documentation and selected final assets.
- Google Drive: approved source renders, high-resolution visual masters, storyboard frames and future video exports.

No production code is modified by this visual workstream.
