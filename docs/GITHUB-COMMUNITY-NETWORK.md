# MyZubster GitHub Community Network

This page maps public GitHub identities that visibly connect back to MyZubster.

The goal is discoverability and transparent contribution paths, not artificial popularity. Multiple accounts controlled by the same operator are listed as **project/operator accounts**, while autonomous people are listed separately as **independent contributor profiles**.

## Recommended profile pattern

Each public profile that chooses to participate can expose a small, verifiable path:

```text
GitHub profile
→ short bio
→ MyZubster link
→ public repository / contribution
→ Zorgax profile
→ optional Metaverse character
→ optional comic/visual node
```

The important signal is not the number of accounts. Useful GitHub signals come from authentic public activity: reviewed pull requests, issues, commits, forks, stars from independent users, documentation, tests and reproducible contributions.
