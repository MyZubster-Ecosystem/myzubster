# MYZ-188 — University → Developer → Community E2E pilot

## Purpose

This pilot demonstrates the MyZubster ecosystem wiring using three **MyZubster-owned public profile/template repositories**:

- University / Research: `DanielIoni-creator/myzubster-university-research`
- Developer: `DanielIoni-creator/Myzubster-developer-support`
- Community: `DanielIoni-creator/Myzubster-community-dao`

It is a technical interoperability pilot. It does not establish external university endorsement, institutional partnership, employment, funding, bounty approval, payment, or community governance approval.

## Canonical flow

```text
University actor
   ↓
GitHub issue #1335
   ↓
Developer implementation commit
   ↓
Community validation record
   ↓
SHA-256 knowledge evidence
   ↓
Ecosystem Contribution Graph
   ↓
Knowledge Explorer
```

## Runtime seed

The seeder is intentionally explicit and does not run automatically.

Required environment:

```text
MONGODB_URI=<authorized MongoDB URI>
MYZ_ECOSYSTEM_SEED_USER_ID=<existing authorized MyZubster User ObjectId>
GITHUB_TOKEN=<optional, recommended for GitHub API rate limits>
```

Run:

```bash
node scripts/ecosystem/seed-myz-188-pilot.js
```

The script verifies the public GitHub identities/repositories and the GitHub issue/commit references before upserting the actor and contribution records.

## Graph smoke

After seeding:

```text
GET /api/ecosystem/graph?projectId=myz-188-university-developer-community
```

Expected graph content:

- 3 actor nodes;
- 3 contribution nodes;
- 1 shared project node;
- GitHub source/repository nodes;
- SHA-256 evidence node;
- `CONTRIBUTED`, `PART_OF_PROJECT`, `SUPPORTED_BY_GITHUB` and evidence edges.

## Current verification boundary

The code, manifest, issue, implementation commit and validation record exist in GitHub. Runtime seeding against an authorized production/staging MongoDB and the final HTTP graph smoke remain separate operational gates.

GitHub Actions must also not be described as green while the known account-level Actions restriction remains unresolved.
