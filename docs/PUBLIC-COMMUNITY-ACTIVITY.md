# MyZubster — Public Community & External Web Activity

_Last reviewed: 2026-09-05_

This page exposes an **evidence-first view of public interaction with and external mentions of the MyZubster ecosystem**. It intentionally distinguishes public contribution evidence from editorial/social mentions and does not identify passive repository visitors.

## What counts here

A person/account is listed as a contributor only when a public GitHub artifact provides verifiable evidence of interaction, such as a merged pull request, issue/report, review, or other attributable public contribution.

External articles, social posts and community discussions are recorded separately as **mentions**. A mention is evidence of public visibility, not proof of adoption, endorsement, partnership, validation, funding or commercial use.

Passive views, anonymous clones, stars by themselves, unchanged forks and maintainer-only tests are **not treated as verified adoption**.

## Public interaction vs website analytics

MyZubster separates three signals:

```text
Vercel Web Analytics
  → anonymous website traffic / page usage

GitHub public evidence
  → attributable issues / PRs / reviews / contributions

External web/social mentions
  → public visibility / discussion, with independence assessed separately

Together
  → interest + visibility + independently verifiable participation
```

Website analytics must not be used to infer a visitor's identity. GitHub aliases should only be connected to activity that the account has made public itself.

## Privacy and interpretation boundary

This page is not a visitor-tracking database. It contains only public contribution evidence already attributable on GitHub and public web/social mentions. Do not attempt to deanonymize passive visitors or correlate website analytics with GitHub identities without an explicit, legitimate and privacy-respecting basis.

**Views are interest. Mentions are visibility. Public contributions are evidence. Adoption requires stronger independent proof.**
