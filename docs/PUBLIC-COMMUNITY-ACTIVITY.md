# MyZubster — Public GitHub Community Activity

_Last reviewed: 2026-08-25_

This page exposes an **evidence-first view of public interaction with the MyZubster ecosystem**. It intentionally does not identify passive repository visitors: GitHub does not provide a reliable public identity for people who only view a repository.

## What counts here

A person/account is listed only when a public GitHub artifact provides verifiable evidence of interaction, such as a merged pull request, issue/report, review, or other attributable public contribution.

Passive views, anonymous clones, stars by themselves, unchanged forks, maintainer-only tests and promotional mentions are **not treated as verified adoption**.

## Public interaction vs website analytics

MyZubster separates two signals:

```text
Vercel Web Analytics
  → anonymous website traffic / page usage

GitHub public evidence
  → attributable issues / PRs / reviews / contributions

Together
  → interest + independently verifiable participation
```

Website analytics must not be used to infer a visitor's identity. GitHub aliases should only be connected to activity that the account has made public itself.

## Privacy and interpretation boundary

This page is not a visitor-tracking database. It contains only public contribution evidence already attributable on GitHub. Do not attempt to deanonymize passive visitors or correlate website analytics with GitHub identities without an explicit, legitimate and privacy-respecting basis.

**Views are interest. Public contributions are evidence. Adoption requires stronger independent proof.**
