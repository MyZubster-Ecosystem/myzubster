# MyZubster Media & Journalist Program

_Status: public contributor program · evidence-first_

MyZubster welcomes journalists, independent reporters, editors, documentary makers, technical writers, fact-checkers and media researchers as public contributors and observers of the ecosystem.

The purpose is **not** to turn journalists into promoters. The purpose is to make it easier for media professionals to inspect claims, follow evidence, ask questions, reproduce public workflows and attach their public reporting contributions to an optional MyZubster character.

## Join as a journalist

1. Read the official Press & Media Kit: https://www.myzubster.com/press
2. Read [`JOIN.md`](../JOIN.md) and [`CONTRIBUTING.md`](../CONTRIBUTING.md).
3. Choose a public GitHub alias or professional identity you are comfortable using publicly.
4. Open or join a public issue relevant to your reporting/research.
5. Optionally create a Media / Journalist Character through Character Registry #617.
6. Link public reporting, fact-checks, interviews, reproducible tests or corrections as evidence where appropriate.

## Media Character

A Media Character is an optional public contributor identity inside the MyZubster narrative/community layer.

Suggested schema:

```yaml
character_type: media_journalist
public_name: "chosen public name or alias"
status: proposed
role: "journalist | reporter | editor | fact-checker | media researcher | documentary maker"
languages: []
beats: []
affiliation_claim: null
verified_affiliation: false
verification_evidence: null
public_links: []
contribution_sources: []
consent_source: null
```

Do not include private contact information, identity documents or unnecessary personal data in the public registry.

## Status and verification boundaries

A character must never imply credentials that have not been verified.

### Community Journalist
A self-declared public role in the MyZubster community. This does **not** mean that MyZubster has verified the person's professional identity or employer.

### Affiliation Verified
May be used only when there is appropriate public or authorized evidence connecting the contributor to the stated media organization. Verification confirms the evidence checked; it does not imply that the organization endorses MyZubster.

### Independent Media Contribution
May be attached to a specific public article, report, interview, test or fact-check produced independently of MyZubster's own project communications.

The following equivalences are explicitly false:

```text
MyZubster Media Character ≠ verified journalist
verified affiliation ≠ employer endorsement
article about MyZubster ≠ partnership
community participation ≠ editorial approval
press access ≠ payment or sponsorship
```

## Editorial independence

Journalists and media contributors remain editorially independent. Participation in the program does not require positive coverage and does not grant MyZubster editorial control.

Critical reporting, corrections and reproducible challenges are valid contributions when made in good faith and supported by evidence.

Sponsored, commissioned or otherwise materially compensated content must be disclosed according to applicable rules and the publisher's own standards.

## Evidence workflow

```text
PRESS KIT / PUBLIC SOURCE
        ↓
MEDIA CHARACTER (OPTIONAL)
        ↓
QUESTION / CLAIM TO VERIFY
        ↓
SOURCE + REPOSITORY + EVIDENCE REVIEW
        ↓
INDEPENDENT REPORT / TEST / FACT-CHECK
        ↓
PUBLIC LINK / CORRECTION / EVIDENCE
        ↓
CHRONICLE / COMMUNITY EVIDENCE (WHEN APPROPRIATE)
```

A journalist may inspect MyZubster without creating a character or contributor account.

## What media contributors can do

- follow public releases, pilots and roadmap milestones;
- inspect repository history and implementation evidence;
- ask for clarification through public project channels;
- reproduce public technical workflows;
- submit factual corrections;
- publish independent articles, interviews or investigations;
- contribute translations or explanatory reporting;
- follow evidence related to Zorgax, DAO, environmental pilots and international replication;
- link a public report to an optional Media Character.

## Privacy and safety

Never publish credentials, private keys, wallet seeds, restricted partner datasets, unnecessary personal information or sensitive locations. Public evidence must be sanitized and authorized.

Embargoes, confidential briefings or private-source handling require a separate explicit process; nothing in this public program creates confidentiality obligations automatically.

## AI and Zorgax boundary

Zorgax may help surface public project sources, organize evidence or prepare a draft summary. It must not impersonate a journalist, fabricate quotes, invent affiliations, determine editorial conclusions or label an affiliation as verified without evidence and the required review.
