# Singapore TOKEN Use Case Proposal

## Status: PROPOSED

## Obiettivo
Inserire il filone TOKEN riferito a Singapore nel framework multi-comune e multi-progetto di MyZubster, come possibile caso d'uso internazionale.

## Collegamenti Framework
- Framework multi-comune: #469–#471
- Treasury / funding: #464
- Verifica / reporting: #465
- Urban Lab: #438–#440
- Progetti pilota: #466–#472

## Perimetro
Definire, solo dopo validazione, eventuali use case per token, incentivi digitali e bounty collegati a progetti o organizzazioni operanti a Singapore.

## Reward
MYZ / XMR / TOKEN secondo regole di funding e settlement formalmente approvate.

## Regole
Questo collegamento non implica partnership, approvazione, autorizzazione normativa o accordo con Singapore, enti pubblici o soggetti privati locali. Qualsiasi token deve essere sottoposto alle verifiche legali, regolamentari e tecniche applicabili prima dell'attivazione.

## Workflow
PROPOSED → VALIDATED → APPROVED → FUNDED → ACTIVE → VERIFIED → PAID

## Exit Criteria
- Use case identificato
- Soggetto referente verificato
- Compliance valutata
- Funding approvato
- Criteri di verifica definiti
