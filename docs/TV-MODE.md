# MyZubster TV Mode

`public/tv.html` is a large-screen, remote-first web view for televisions and living-room browsers, including Google TV browsers where a normal web page can be opened.

## Purpose

The TV surface follows the clarity-first narrative:

`OBSERVE -> REPORT -> ACT -> VERIFY -> IMPACT`

It intentionally introduces the simple public story before exposing the broader MyZubster ecosystem.

## Interaction

- Large typography and high-contrast focus states.
- Arrow-key / D-pad navigation between primary actions.
- Enter activates the focused native link.
- Responsive fallback for narrow displays.

## Evidence boundary
