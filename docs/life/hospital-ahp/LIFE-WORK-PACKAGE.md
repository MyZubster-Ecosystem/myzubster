# LIFE Work Package — Hospital AHP/PAP Pilot

Status: `PROPOSED / READY FOR PARTNER VALIDATION`

## Obiettivo
Tradurre il pilot ospedaliero AHP/PAP in un work package operativo con attività, deliverable, milestone e responsabilità verificabili.

## WP0 — Validazione del processo reale
**Attività**
- confermare flusso ospedale → pesatura → trasporto → impianto;
- identificare quali registri e dati esistono già;
- confermare attori e confini di responsabilità;
- definire dati pubblici, privati e non utilizzabili.

**Deliverable**
- process map validata;
- data inventory;
- lista attori/owner;
- privacy/compliance boundary.

## WP1 — Data model e tracciabilità
**Attività**
- definire ID lotto/contenitore/evento;
- formalizzare `pre_transport_weighing`;
- collegare ritiro, ricezione impianto, trattamento e recupero;
- definire audit trail e gestione rettifiche.

**Deliverable**
- schema dati;
- esempi validi/invalidi;
- mapping tra eventi e documenti.

## WP2 — KPI / MRV
**Attività**
- raccogliere baseline;
- validare KPI;
- definire formule, owner, frequenza e soglie qualità;
- distinguere `DECLARED`, `MEASURED`, `DOCUMENTED`, `CROSS_CHECKED`, `VERIFIED`.

**Deliverable**
- KPI/MRV framework validato;
- baseline report;
- data-quality rules.

## WP3 — Evidence Layer
**Attività**
- collegare misura, documento e evento;
- implementare cross-check peso origine vs ingresso impianto;
- tracciare quantità trattata e materiali recuperati;
- usare hash/firma solo quando utile per integrità/provenienza.

**Deliverable**
- evidence chain;
- anomaly report;
- evidence pack template.

## WP4 — Pilot execution
**Attività**
- selezionare sito/i candidato/i;
- eseguire una finestra di raccolta dati concordata;
- monitorare completezza, anomalie e carico operativo;
- raccogliere feedback degli operatori.

**Deliverable**
- pilot dataset autorizzato;
- dashboard/report;
- operator feedback;
- issue log.

## WP5 — Verification, replication & scale-up
**Attività**
- review scientifica/MRV;
- validazione dei risultati;
- definizione dei limiti;
- preparazione replication checklist per altri ospedali/territori.

**Deliverable**
- verification report;
- lessons learned;
- replication package;
- scale-up recommendations.

## Milestone proposte
- **M1** processo e dati esistenti validati
- **M2** schema + KPI/MRV approvati
- **M3** Evidence Layer pronto per test
- **M4** pilot eseguito
- **M5** risultati verificati e replication package pronto

## Dipendenze
Nessuna attività va considerata formalmente avviata finché il relativo partner/owner non conferma ruolo, dati e perimetro.
