# LIFE Pilot Work Package — Hospital AHP/PAP

Status: `PROPOSED / READY FOR PARTNER VALIDATION`

## Obiettivo del Work Package
Preparare, testare e validare un pilot ospedaliero AHP/PAP che colleghi la pesatura pre-trasporto con ricezione, trattamento, recupero materiali e Evidence Layer MyZubster.

## Attività proposte
### T1 — Baseline e processo reale
- mappare il processo attuale;
- identificare dove e come avviene la pesatura;
- censire registri/documenti disponibili;
- definire baseline e qualità dei dati.

### T2 — Data model e interoperabilità
- adottare lo schema `pre_transport_weighing`;
- definire identificativi lotto/contenitore;
- collegare trasporto e ricezione impianto;
- definire formati import/API.

### T3 — KPI/MRV ed Evidence Layer
- validare KPI con partner tecnici/scientifici;
- definire livelli di evidenza;
- implementare controlli incrociati;
- preparare report riproducibili.

### T4 — Pilot operativo
- raccolta dati autorizzati;
- confronto peso pre-trasporto vs ingresso impianto;
- registrazione trattamento e recupero;
- verifica anomalie e data quality.

### T5 — Validazione e replicabilità
- review risultati;
- raccolta feedback degli attori;
- definizione requisiti minimi per replica;
- Evidence Pack finale.

## Deliverable candidati
- D1: process map + baseline
- D2: data schema + interoperability note
- D3: KPI/MRV protocol
- D4: pilot evidence dataset/report
- D5: replication package

## Milestone candidati
- M1: processo e fonti dati confermati
- M2: schema e KPI validati
- M3: prima catena completa di evidenze
- M4: pilot review completata

## Ruoli da assegnare
- pilot owner / struttura sanitaria
- waste/logistics operator
- treatment/recycling operator
- MRV/scientific reviewer
- MyZubster technical maintainer

Nessun ruolo è considerato assegnato finché non viene confermato esplicitamente.
