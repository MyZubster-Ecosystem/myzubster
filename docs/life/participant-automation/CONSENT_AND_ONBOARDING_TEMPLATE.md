# Consent and onboarding templates

Sostituire tutti i campi tra parentesi quadre. Conservare la versione inviata e non considerare il silenzio come consenso.

## A. Email di consenso

**Oggetto:** `[Nome] - consenso per attivare Zorgax sul profilo MyZubster`

Ciao `[Nome]`,

ti proponiamo di attivare **Zorgax Participant Profile Automation v1.0** per il tuo percorso MyZubster.

Se accetti, Zorgax potrà utilizzare soltanto le informazioni che fornisci o confermi relative a:

- presentazione pubblica del profilo;
- obiettivi, interessi e competenze dichiarate;
- stato dei progetti autorizzati;
- attività completate ed evidenze raccolte;
- prossime azioni e decisioni confermate;
- risultati misurati e verificabili.

Il processo è:

```text
CONSENSO -> DATI AUTORIZZATI -> BOZZA -> PRIVACY/ACCURATEZZA
-> BRANCH -> COMMIT -> PULL REQUEST -> REVISIONE UMANA
```

Zorgax non può pubblicare automaticamente, eseguire merge, spendere denaro, effettuare pagamenti o compiere azioni commerciali sensibili. Non inviare password, token, codici OTP/2FA, chiavi private, dati bancari, documenti o indirizzi privati.

Puoi revocare o restringere il consenso in qualsiasi momento.

Per accettare, rispondi:

> Confermo il consenso ad attivare Zorgax Participant Profile Automation v1.0 per il mio profilo MyZubster, limitatamente ai dati e alle attività descritti in questa email. Ho capito che posso revocare o restringere il consenso in qualsiasi momento e che le azioni pubbliche o sensibili restano sotto controllo umano.

## B. Questionario profilo

1. Come vuoi essere presentato pubblicamente in 2-3 frasi?
2. Quali sono i tuoi principali interessi?
3. Quali competenze possiedi già?
4. Quali competenze vuoi imparare o migliorare?
5. Quali strumenti digitali utilizzi già?
6. Cosa vuoi costruire nei prossimi mesi?
7. Quali prodotti o progetti ti interessano?
8. Quali lavori o esperimenti possiamo citare pubblicamente?
9. In cosa vuoi che Zorgax ti aiuti?
10. Cosa vuoi escludere dal profilo pubblico?

## C. Collegamento ChatGPT, Gmail e GitHub

1. Accedi a ChatGPT con l'account scelto per il percorso.
2. Apri `Plugins` oppure `Impostazioni > Apps`, secondo l'interfaccia disponibile.
3. Installa e collega Gmail; approva soltanto i permessi necessari.
4. Installa e collega GitHub; limita l'accesso ai repository necessari.
5. Torna in ChatGPT Work e verifica che entrambi risultino collegati.
6. Prova soltanto azioni di lettura: trovare l'ultima email LIFE e leggere una PR indicata.
7. Non inserire credenziali nella chat; usarle solo nelle schermate ufficiali di accesso.
8. Comunica: Gmail collegato sì/no, GitHub collegato sì/no, repository visibile sì/no, errore eventuale.

## D. Revoca o restrizione

> Revoco il consenso a Zorgax Participant Profile Automation v1.0.

oppure:

> Limito il consenso ed escludo `[informazione o attività]`.

La revoca o restrizione deve essere applicata prima di qualunque nuova modifica.
