# Community Circular Events Pilot Toolkit

**Status:** working toolkit for a candidate LIFE-oriented demonstration track. This is not a confirmed LIFE project, partnership, funding decision, or authorised event deployment.

This folder turns the high-level `community-circular-events-pilot.md` concept into an operational evidence-building toolkit.

## Files

- [`stakeholder-register-template.md`](./stakeholder-register-template.md) — explicit stakeholder status, consent, contact and evidence fields.
- [`material-evidence-schema.md`](./material-evidence-schema.md) — minimum material/passport, provenance, use-cycle and evidence model.
- [`pilot-protocol-v0.1.md`](./pilot-protocol-v0.1.md) — pre-pilot, deployment, recovery, KPI and replication protocol.

## Core rule

`social interest != stakeholder commitment != pilot participation != partnership != environmental evidence`

The pilot can only move forward when each transition is supported by explicit evidence and the environmental methodology has been validated by a competent partner.

## Operational sequence

`social discovery -> stakeholder register -> role/consent verification -> authorised pilot -> baseline -> material registry -> use/reuse events -> recovery -> validation -> KPI -> replication package`

## Boundaries

- Cultural references or community interest do not create formal affiliations.
- Spiral Tribe/SP23 or any other collective must not be represented as a partner without explicit, independently verifiable confirmation.
- Environmental impact claims require baseline, method, measurement and validation.
- Sensitive locations, personal data, credentials and private contact information must not be published by default.
- Reused materials must be fit and safe for their intended real-world use; the registry is not a substitute for legal or technical safety assessment.
