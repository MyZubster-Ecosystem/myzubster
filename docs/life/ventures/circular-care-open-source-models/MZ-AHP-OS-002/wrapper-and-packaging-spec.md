# MZ-AHP-OS-002 — Wrapper and Packaging Specification v0.3-draft

Status: `DESIGN_REFERENCE / NOT PRODUCTION-VALIDATED`

This file defines the wrapper, release-liner and outer-packaging architecture to be tracked with the Circular Menstrual Pad reference model. It is not a packaging-compliance approval, recycling claim or shelf-life validation.

## Baseline system

| Element | Candidate architecture | Draft target | Evidence state |
| --- | --- | ---: | --- |
| Release liner | siliconized paper or separable polyolefin film | 0.60 g / unit | `DESIGN_TARGET_NOT_VALIDATED` |
| Individual wrapper | PE or PP flexible film where feasible | 0.80 g / unit | `DESIGN_TARGET_NOT_VALIDATED` |
| Outer packaging allocation | PE or PP flexible pack | 0.35 g / unit | `DESIGN_TARGET_NOT_VALIDATED` |
| Print / label | minimum practical ink/label area; exact chemistry declared | not fixed | `NOT_VERIFIED` |

These values are design targets for material accounting only. Actual masses must be measured from prototypes and production samples.

## Functional requirements to validate later

The wrapper/packaging system should eventually demonstrate, through qualified evidence:

- hygienic protection during normal storage/handling;
- wrapper opening without damaging the pad;
- release-liner removal without adhesive transfer outside the intended area;
- readable model/lot identification;
- package integrity for the intended distribution route;
- declared material composition;
- confirmed local end-of-life route before any recycling/circularity instruction is published.

## Required information

Prototype packaging should expose or encode:

- model ID: `MZ-AHP-OS-002`;
- design version;
- prototype lot ID;
- product count;
- material declaration reference;
- wrapper/release-liner material reference;
- manufacturing/assembly evidence reference when available;
- storage information from qualified suppliers/manufacturers when available;
- collection/disposal guidance only where a real route is evidenced;
- QR/equivalent link to MyZubster material-passport/evidence records where practical.

## Circular-design rules

1. Release liner, individual wrapper and outer pack are never omitted from material accounting.
2. Prefer simplified, explicitly declared material families when functional requirements allow.
3. Avoid unnecessary laminates, metallic layers, decorative coatings or mixed-material labels unless justified and documented.
4. Do not infer recyclability from resin family alone.
5. Package and wrapper changes require a version/change record.
6. Any local collection claim needs a confirmed real-world route and evidence reference.

## Prototype checks

Record:

- individual wrapper mass;
- release-liner mass;
- outer-pack mass and unit count;
- allocated outer-pack mass per unit;
- seal/closure observations;
- wrapper tear/opening observations;
- adhesive transfer observations;
- basic manual handling/drop observations;
- lot/label readability;
- supplier material declaration when available.

## Claim boundary

This design reference does not establish hygiene compliance, shelf life, dermatological suitability, recyclability, compostability, environmental benefit or market compliance.
