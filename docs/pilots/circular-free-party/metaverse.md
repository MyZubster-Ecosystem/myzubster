# Metaverse Node Model

The Metaverse layer should make the pilot understandable at a glance and connect digital exploration to real-world action.

## Node contents

- pilot title and short description
- current status
- participant roles
- resource-flow map
- latest GitHub issues and pull requests
- Marketplace entries related to the pilot
- KPI/impact snapshot
- Zorgax entry point
- links to real-world pilot evidence

## Suggested metadata

```json
{
  "id": "circular-free-party-community-economy",
  "title": "Circular Free-Party Community Economy",
  "type": "pilot",
  "status": "definition",

  "campaign": "circular_free_party_pilot"
}
```

## User journey

1. Visitor enters the Metaverse node.
2. Reads the pilot purpose and sees current resource flows.
3. Opens Zorgax for guidance.
4. Chooses to contribute a resource, skill, idea or code/documentation change.
5. Continues to GitHub or Marketplace.
6. Returns to the node to see evidence and impact updates.

## Design principle

The Metaverse representation should not replace real-world activity. It should make participation, evidence and coordination easier.
