# KPI and MRV Starter Framework

MRV means Measurement, Reporting and Verification. This starter framework keeps the first pilot measurable without making participation overly complex.

## Core KPIs

### Circularity
- kilograms/items of material reused
- items repaired
- items diverted from disposal
- shared equipment actions
- recovered materials reintroduced into use

### Logistics
- shared transport actions
- estimated avoided duplicate trips
- storage or infrastructure shared

### Community
- active contributors
- organizations/communities participating
- GitHub issues opened
- pull requests submitted/merged
- documented skills contributed

### Digital engagement
- Zorgax onboarding completions
- visits to pilot pages
- Marketplace listings/exchanges related to the pilot
- Metaverse node visits
- tracked campaign visits via UTM links

## Minimum evidence

Each reported result should include at least one of:

- photo or document link
- GitHub issue/PR
- Marketplace entry
- transaction/exchange record
- event log
- participant confirmation
- simple before/after measurement

## Reporting cadence

For the first pilot, report after each real-world test. If the pilot becomes recurring, move to a monthly summary.

## Example pilot record

- Action: repaired and reused 4 lighting fixtures
- Resource type: technical equipment
- Participants: 3
- Avoided disposal: 4 items
- Evidence: GitHub issue + photos
- Related Marketplace/Metaverse links: optional

## Integrity rule

Do not publish environmental impact estimates as verified facts unless the method and evidence are documented.
