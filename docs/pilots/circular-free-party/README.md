# Circular Free-Party Community Economy

A MyZubster pilot exploring how decentralized community practices, reuse, self-organization, open-source collaboration and measurable circular-economy flows can work together.

> This pilot does not aim to commercialize or appropriate underground/free-party culture. It studies transferable principles such as autonomy, sharing, repair, reuse, creativity, collective infrastructure and open documentation.

## Goal

Turn a real community use case into a documented, measurable circular-economy pilot connected to:

- GitHub for open collaboration and verifiable contributions
- Zorgax for guided onboarding
- MyZubster Marketplace for resources, services and exchanges
- MyZubster Metaverse for a shared digital representation of the pilot
- Analytics/KPIs for evidence and continuous improvement

## Participation flow

**GitHub identity -> Fork -> Contribution -> Pull Request -> Pilot participation -> Marketplace / Metaverse**

You do not need to be a developer. Contributions can include code, documentation, translations, design, testing, logistics, research, circular-economy ideas, community coordination, data collection or real-world pilot activity.

## What can circulate

Examples:

- reusable event materials and equipment
- repairable objects and technical components
- transport and logistics capacity
- tools and shared infrastructure
- creative and technical skills
- recovered materials
- water and local resource systems
- knowledge, documentation and training

See [resources.md](resources.md).

## How Zorgax helps

Zorgax should guide a participant through five questions:

1. What resource, skill, material or community do you want to connect?
2. Can it be reused, repaired, shared, exchanged or recovered?
3. Do you want to contribute through GitHub, Marketplace or a pilot node?
4. What evidence or KPI can show real impact?
5. Should the project also have a Metaverse space?

See [zorgax-onboarding.md](zorgax-onboarding.md).

## Metaverse layer

The pilot can have a digital node that shows:

- pilot description
- participant roles
- resource flows
- GitHub issues and pull requests
- Marketplace entries
- impact/KPI board
- Zorgax entry point

See [metaverse.md](metaverse.md).

## Measurement

Suggested KPIs include:

- materials reused
- items repaired
- waste avoided
- shared logistics actions
- active contributors
- GitHub issues and PRs
- Marketplace exchanges
- Zorgax onboarding completions
- Metaverse visits

See [kpi.md](kpi.md).
