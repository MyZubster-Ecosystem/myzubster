# Resource Map

This document defines the first resource categories for the Circular Free-Party Community Economy pilot.

## Resource categories

### Materials and equipment
- reusable structures, furniture and event materials
- cables, lighting, sound and technical components
- repairable tools and hardware
- recovered wood, metal, plastics and textiles

### Logistics
- transport capacity
- shared vehicle space
- storage
- setup and teardown support
- repair and maintenance capacity

### Skills
- audio and lighting
- electronics
- mechanics
- carpentry and fabrication
- design and visual communication
- software and open-source development
- coordination and documentation

### Local circular systems
- water refill and reuse
- waste sorting and recovery
- food surplus redistribution
- reusable containers
- energy-sharing or low-impact power solutions

## Resource-flow record

Each pilot resource should record:

- resource name
- category
- provider/contributor
- location or node
- quantity/unit
- condition
- action: share / reuse / repair / recover / exchange
- destination or beneficiary
- date
- evidence link
- estimated waste/resource savings

## Principle

Prefer extending useful life, reducing waste and sharing existing capacity before purchasing new resources.
