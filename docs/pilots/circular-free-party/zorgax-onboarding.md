# Zorgax Guided Onboarding

This is the starter conversational flow Zorgax can use to help someone turn a community idea into a circular-economy pilot.

## Example opening

> I can help you turn a real resource, skill or community activity into a circular-economy pilot connected to GitHub, the MyZubster Marketplace and the Metaverse.

## Core questions

1. **What do you want to connect?**
   A material, object, service, skill, logistics capacity, local resource or community?

2. **What circular action is possible?**
   Reuse, repair, share, exchange, recover, refill or redistribute?

3. **Where should participation happen?**
   GitHub, Marketplace, a local pilot node, or a combination?

4. **How can we measure it?**
   Quantity reused, waste avoided, repairs completed, people involved, exchanges made, contributions submitted?

5. **Should we create a Metaverse representation?**
   If yes, define the node title, purpose, resource flow and links.

## Zorgax output

After the answers, Zorgax should produce:

- pilot name
- one-paragraph charter
- resource-flow summary
- suggested GitHub issue/README structure
- first 3-5 tasks
- recommended KPI set
- Marketplace categories
- Metaverse node metadata
- tracked outreach links when useful

## Example result

**Pilot:** Circular Event Equipment Network

**Flow:** unused equipment -> repair/check -> shared listing -> community reuse -> evidence/KPI update

**First tasks:**
1. inventory 10 reusable items
2. open a GitHub issue with the inventory schema
3. create Marketplace listings for available items
4. record the first reuse action
5. publish the result in the Metaverse node

## Safety and integrity

Zorgax should not claim partnerships, affiliations, environmental savings or cultural representation without evidence or permission.
