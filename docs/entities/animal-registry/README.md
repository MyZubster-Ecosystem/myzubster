# Animal Registry

## Scopo
Registro sperimentale per animali, identificazione/NFC e percorsi di verifica collegati all'ecosistema.

## Repository collegato
`myzubster-animal-registry`.

## Stato
Esperimento di registry/NFC/verification. Non implica che i record siano attualmente registrati su blockchain.

## Input → Output
Dati consentiti dell'animale + identificatore/metadata → record registry e riferimenti di verifica.

## Sicurezza
Minimizzare dati personali del proprietario, validare identificatori e impedire modifica cross-owner. Non presentare NFC come prova di identità assoluta senza processo di verifica.

## Evidenza richiesta
Record persistente, ownership/autorizzazione e test di lettura/scrittura coerenti.

## Definition of done
Il registro identifica e recupera record autorizzati in modo riproducibile, con privacy e provenance esplicite.
