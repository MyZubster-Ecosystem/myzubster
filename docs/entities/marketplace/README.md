# Marketplace

## Scopo
Superficie marketplace per servizi, offerte ed esperimenti collegati all'ecosistema MyZubster.

## Repository collegato
`MyZubster-Marketplace`.

## Stato
Application/service surface in sviluppo. Eventuali claim storici di reward o pagamento restano separati dall'evidenza di settlement verificato.

## Input → Output
Listing/offerta/richiesta validata → interazione marketplace e, dove previsto, collegamento ai workflow bounty/reward.

## Sicurezza
Validare identità/ownership lato server, prezzi/importi e autorizzazioni. Nessuna credenziale payment nel client o nei log pubblici.

## Evidenza richiesta
Transazione applicativa e stato marketplace non equivalgono a pagamento esterno. Il settlement richiede il relativo verifier.

## Definition of done
Listing e operazioni sono autorizzati e testati; qualsiasi pagamento è classificato separatamente e solo con evidenza adeguata.
