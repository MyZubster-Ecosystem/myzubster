# Documentation / Manuals

## Scopo
Hub di guide, runbook e documentazione cross-repository per rendere l'ecosistema comprensibile e verificabile.

## Repository collegati
`myzubster-docs`, `myzubster-manuals`, cartella `docs/` del core.

## Stato
Documentazione attiva. Un documento descrive stato e procedure, ma non sostituisce test, CI o verifica fisica.

## Input → Output
Codice, PR, workflow, fonti primarie e decisioni approvate → guide, runbook, checklist e mappe architetturali.

## Sicurezza
Nessun secret, token, password, seed, private key o dato personale non necessario nei documenti o screenshot.

## Evidenza richiesta
Link al codice/PR/workflow pertinente, maturity state e distinzione tra documentato, implementato e verificato.

## Definition of done
La guida è aggiornata, non contraddice il comportamento verificato e rende espliciti prerequisiti, limiti e source of truth.
