# Observations

## Scopo
Raccoglie osservazioni e relativa evidenza: foto, metadata e dati ambientali consentiti, mantenendo separati fatti osservati e interpretazioni.

## Componenti collegati
Core API, App, crawler, public snapshots/IPFS.

## Stato
Parte del dominio core in sviluppo/validazione.

## Input → Output
Evidenza utente/sensore validata → observation record, eventuale media CID/snapshot pubblico sanitizzato.

## Sicurezza
Non pubblicare dati personali non necessari, geolocalizzazioni sensibili, infrastrutture ristrette o file privati. Validare MIME, dimensione e metadata.

## Evidenza richiesta
Origine, timestamp dove appropriato, integrità del file/record e distinzione tra raw evidence e classificazione derivata.

## Definition of done
L'osservazione è riproducibilmente registrata, sanitizzata, autorizzata e distinguibile da illustrazioni o contenuti narrativi.
