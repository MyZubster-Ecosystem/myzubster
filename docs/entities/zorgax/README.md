# Zorgax

## Scopo
Livello operativo e narrativo evidence-first dell'ecosistema MyZubster: osserva stato, CI, sicurezza, documentazione, adozione e Chronicle senza trasformare ipotesi in fatti.

## Componenti collegati
`docs/ZORGAX_SYSTEM.md`, automazioni, GitHub, Chronicle/Drive, TV e character context dove consentito.

## Stato
Sistema operativo/documentale in sviluppo continuo con supervisione umana.

## Input → Output
Evidenza repository/CI/fonti primarie → diagnosi, Draft PR, documentazione, classificazioni conservative e asset con provenance.

## Sicurezza
Niente merge automatici, force push, modifiche a segreti, billing, permessi o dati persistenti. Non leggere/pubblicare token, password, seed o private key.

## Evidenza richiesta
Separare `sintomo`, `causa`, `ipotesi`; distinguere REAL EVIDENCE, DOCUMENTATION_VISUAL e NARRATIVE_ILLUSTRATION.

## Definition of done
Ogni intervento è delimitato, verificabile, su branch dedicato/Draft PR e non dichiara capacità, adozione o pagamenti senza prova adeguata.
