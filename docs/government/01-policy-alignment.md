# MyZubster — Government Policy Alignment Framework

**Status:** working framework; policy alignment is not evidence of funding or endorsement.

## Strategic mapping

| Public priority | MyZubster capability | Evidence needed | Status |
|---|---|---|---|
| Digital public services | Institutional gateway + dashboard | Pilot institution | Candidate |
| Interoperability | APIs + structured registry/evidence | API specification + integration test | In progress |
| Cybersecurity/privacy | Onion institutional-access layer | Threat model + security review | In progress |
| Park digitisation | Nature registry + field workflow | Protected-area pilot | Candidate |
| Nature monitoring | Observation → evidence → dashboard | Scientific methodology + baseline | Not yet validated |
| Biodiversity conservation | Nature pilot + measurable outcomes | Scientific partner + KPI | Not yet validated |
| Replication | Reusable data model and deployment pattern | Second site/replication plan | Planned |

## Important distinction

MyZubster should describe itself as **aligned with public policy directions** only where a current policy document supports the mapping. It should not be described as a government programme, PNRR project or publicly funded initiative without a specific official act, award, agreement or funding instrument.

## Funding workstream

The next step is not to collect generic references to government strategy. It is to identify concrete instruments where MyZubster is eligible and where the project can satisfy the actual applicant, partnership, timing and co-financing requirements.

## Positioning

Preferred institutional framing:

> MyZubster is a digital evidence and monitoring infrastructure that can support institutional workflows for biodiversity, protected-area management and interoperable environmental data.

Avoid positioning the project primarily as:

- a crypto/token project;
- a generic social network;
- a generic AI platform;
- a Tor project;
- an app seeking funding without a defined public/environmental outcome.
