# 🌍 MyZubster — Universal / Multilingual Guide

This page explains the same MyZubster model in multiple languages so contributors can understand the project before reading repository-specific technical documentation.

> **Canonical truth:** translations must never change the technical meaning. If a translation conflicts with [`docs/ECOSYSTEM.md`](../ECOSYSTEM.md) or [`BOUNTIES.md`](../../BOUNTIES.md), the canonical technical documents prevail.

## Universal flow

```text
REAL-WORLD OBSERVATION / CONTRIBUTION
                ↓
        EVIDENCE + METADATA
                ↓
         PRIVACY / SAFETY
                ↓
           SHA-256 / CID
                ↓
      SUBMISSION / BOUNTY
                ↓
              REVIEW
                ↓
            VERIFIED
                ↓
       REWARD_RECORDED (MYZ)
                ↓
      MYZ INTERNAL LEDGER
                ↓
 OPTIONAL EXTERNAL SETTLEMENT
        XMR / TOKEN / CHAIN
                ↓
   INDEPENDENT VERIFICATION
                ↓
          PAID / SETTLED
```

**Important:** MYZ is currently an internal MyZubster reward/accounting ledger unit. A MYZ reward is not automatically an on-chain transaction. External XMR/token/blockchain settlement is separate and is only `PAID`/`SETTLED` after independent verification.

## Translation policy / More languages

MyZubster welcomes additional translations. A translation should preserve these non-negotiable facts:

1. MyZubster is an evolving open-source ecosystem, not a claim that every planned feature is deployed.
2. Evidence and repository presence do not automatically prove bounty verification.
3. MYZ is currently an internal platform reward/accounting ledger unit.
4. A MYZ reward must not be described as an on-chain payment without independent chain evidence.
5. XMR/token/blockchain settlement is a separate state machine and `PAID`/`SETTLED` requires independent verification.
6. Privacy, consent, authorization and physical-world safety are mandatory.

If your language is not listed yet, browser translation can be used as an accessibility fallback, and community-maintained human translations can be added through pull requests.
