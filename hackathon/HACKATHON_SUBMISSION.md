# 📝 Hackathon Submission Template

Use this template when submitting your project for MyZubster Hackathon 2026.

---

## PR Title Format

```
[hackathon-2026] [Track] Project Name (fixes #issue)
```

Examples:
- `[hackathon-2026] [AI] Plant Disease Detector`
- `[hackathon-2026] [Mobile] Garden Journal App`
- `[hackathon-2026] [Core] API Rate Limiter`

## ✅ Submission Checklist

Before submitting, make sure you have:

- [ ] Forked the repository
- [ ] Created a feature branch
- [ ] Implemented your project
- [ ] Added tests (if applicable)
- [ ] Updated documentation
- [ ] Created demo/screenshots
- [ ] Filled out the PR template
- [ ] Added XMR payout address
- [ ] Tested everything works
- [ ] Submitted before deadline

## 📁 File Structure

Your submission should follow this structure:

```

├── src/
│   ├── index.js
│   └── ...
├── tests/
│   └── ...
├── docs/
│   └── README.md

```

## 🎨 Demo Requirements

### For UI Projects
- At least 3 screenshots
- Or a 2-minute video demo
- Or a live demo URL

### For API Projects
- API documentation
- Example requests/responses
- Postman collection (optional)

### For Documentation
- PDF or markdown files
- Translation files (if applicable)
- Usage examples
