## 📋 Rules

1. **Team Size:** 1-4 people
2. **Code:** Must be open-source (MIT/Apache 2.0)

4. **Existing Code:** You may use existing MyZubster codebase as a foundation
5. **Submission:** GitHub PR with clear description and demo

## 🚀 Getting Started

### Prerequisites
- Git and GitHub account
- Node.js 18+ installed
- Docker (optional, for full stack)
- Monero wallet (for prize receiving)

### Quick Start
```bash
# Clone the repository
git clone https://github.com/MyZubster-Ecosystem/myzubster.git
cd myzubster

# Install dependencies
npm install

# Start development
npm run dev
```
