# MyZubster Comics Bounty Rules

This document narrows the repository-wide bounty rules for comic and visual-storytelling work. It does not replace [`../BOUNTIES.md`](../BOUNTIES.md).

## Reward asset

All comics bounty rewards are denominated only in **MYZ**.

## Required bounty fields

Each `COMIC-BNT-*` challenge should define:

- objective and audience;
- required format and page/panel count where applicable;
- characters, themes and factual constraints;
- visual references that are authorized for use;
- required source/export files;
- acceptance criteria;
- AI-assistance policy;
- rights/license terms if different from the program default;
- MYZ reward amount;
- maximum winners or whether multiple submissions can be rewarded.

## Submission evidence

Depending on the bounty, evidence can include:

- script in Markdown/PDF;
- storyboard pages;
- PNG/JPEG/PDF exports;
- SVG/source files;
- editable production files when explicitly requested;
- GitHub pull request containing text or web-ready assets;
- thumbnails or contact sheets for review.

Do not include private credentials, stock assets without redistribution rights, or licensed fonts/files that cannot legally be redistributed.

## Review

The reviewer evaluates the published criteria. Possible outcomes:

```text
VERIFIED
REVISION_REQUESTED
REJECTED
```

Revision requests should be specific enough for the contributor to understand which acceptance criterion is not yet met.

## Rights

The contributor represents that they have the necessary rights to submit the work.

Unless a bounty explicitly states different terms before work begins, verified/rewarded work grants MyZubster a non-exclusive, worldwide, perpetual right to reproduce, publish, display, distribute and adapt the accepted contribution for project, documentation, community and promotional use. Copyright remains with the creator.

## AI disclosure

When AI-assisted work is allowed, the contributor must disclose material AI assistance. The contributor remains responsible for the final work, rights clearance and compliance with the brief.

## Reward accounting

A verified contribution can create a MYZ reward record. That record documents approved reward accounting; it must not be represented as an external/on-chain transfer unless separate settlement evidence supports that claim.
