# Sound System & Rave Crew Example

Example profile for a sound system, free-party crew, DJ collective or underground cultural group joining MyZubster.

## What we offer
- sound system and technical production
- DJ and live performance support
- lighting and event equipment
- visual art and cultural programming
- community knowledge and DIY skills

## What we need
- developers for websites and digital tools
- venues, logistics and local partners
- artists, technicians and volunteers
- university researchers for cultural and social projects

## Marketplace examples
- sound system rental
- DJ equipment
- event production
- technical crew
- clothing, vinyl, tapes and cultural items

## Zorgax
Zorgax can help structure the crew profile, connect collaborators, organize project needs and document public evidence.

## Safety and legality
This example supports lawful cultural activity only. Do not publish private event locations, personal addresses, unsafe instructions or information that could put participants at risk.
