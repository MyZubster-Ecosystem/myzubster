# Example Repository — Student / Individual Profile

## Who we are
A demonstration profile for a student, graduate, researcher or individual contributor entering MyZubster with skills, learning goals and a possible pilot project.

## Profile sections
- field of study or expertise
- skills and tools
- topics of interest
- GitHub/open-source contributions
- services or help offered to the community
- help or mentoring requested
- potential individual pilot

## Marketplace examples
- tutoring or peer learning
- research assistance
- data analysis
- documentation
- software development
- design or communication support

## Collaboration examples
A student can help a sound system with documentation, an agricultural pilot with data analysis, a developer team with testing, or a community with research and communication.

## Zorgax role
Zorgax can help build the profile, map skills to ecosystem needs, suggest contribution tasks and structure an individual pilot.

## Privacy
Only publish information the participant explicitly wants public. Do not include private contact details, student IDs, private addresses or sensitive personal information.
