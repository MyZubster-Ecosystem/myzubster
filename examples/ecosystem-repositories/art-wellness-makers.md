# Example Repository — Art, Wellness & Makers

## Who we are
A demonstration profile for artists, makers, craftspeople, wellness practitioners and creative community spaces entering the MyZubster ecosystem.

## What we can offer
- visual art and design
- workshops and creative labs
- repair/upcycling activities
- wellness sessions and community care activities
- event visuals, installations and handmade goods
- collaboration with students, developers and local initiatives

## What we need from the ecosystem
- technical support for websites and digital tools
- help with event production and promotion
- shared spaces and equipment
- research/documentation support
- marketplace visibility and community introductions

## Marketplace examples
- workshop booking
- artwork or handmade item listings
- event visual packages
- repair/upcycling services
- shared studio time

## Zorgax role
Zorgax can help structure the profile, describe services, connect collaborators, prepare project briefs and guide onboarding into pilots.

## Public evidence
Use public portfolio links, GitHub contributions, event documentation and project outputs. Do not publish private client data, health data or precise private locations.
