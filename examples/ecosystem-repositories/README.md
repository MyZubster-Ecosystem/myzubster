# MyZubster Ecosystem Example Repositories

This directory contains example repository blueprints for the communities that can enter the MyZubster ecosystem.

Each blueprint is designed to show how a real participant, collective, university group, service provider, pilot or community can structure a public GitHub profile/repository while keeping private information out of the repository.

## Example categories

- University / Research
- Sound System / Rave Crew
- Developer / Technical Support
- Agriculture / Circular Farming
- Fermentation / Kefir Community
- Animals / Pet & Rescue Services
- Art / Wellness / Makers
- Events / Equipment / Production
- LIFE / Circular Economy Pilot

## Common structure

Each example repository should describe:

1. Who we are
2. What we can offer to the MyZubster ecosystem
3. What help we need from other communities
4. Services or resources available through the Marketplace
5. Research, pilot or open-source activities
6. How Zorgax can support onboarding and collaboration
7. Public evidence and GitHub contributions
8. Privacy and safety boundaries

These are demonstration blueprints, not claims that the example organizations or services already exist.
