# PR summary — MyZubster Visual MVP

This branch introduces the first reviewable MyZubster Visual MVP.

## Included

- product specification and privacy boundaries;
- JSON Schema for versioned character profiles;
- example character and collaborative story;
- GitHub Issue template for visual collaboration proposals;
- standalone responsive Create Character browser UI;
- local JSON preview/export;
- pre-filled GitHub Issue handoff;
- `/visual` route in the existing Express service;
- Supertest route smoke test;
- implementation notes and next milestones.

## Not included

Image generation, GitHub OAuth, automatic publishing, server-side persistence and real partnership status are intentionally outside this MVP.
