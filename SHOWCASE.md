# MyZubster Independent Showcase

This showcase lists only public, independently verifiable activity around the MyZubster ecosystem.

It is intentionally stricter than a general community page. Stars, passive views, unchanged forks, maintainer-only demos, promotional mentions and unverified claims are excluded.

## Classification

`CONTRIBUTION` → external substantive code/content/test work submitted to a MyZubster repository.

`INTEGRATION` → a third-party project imports, depends on, calls or otherwise integrates a MyZubster component.

`DEPLOYMENT` → an independent party runs a reproducible or live deployment.

`VERIFIED_ADOPTION` → repeated independent use with public evidence.
